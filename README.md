# มรดกสายน้ำ · กวนวัน หนองคาย

เว็บไซต์ภาษาไทยแบบ Static HTML / CSS / JavaScript ไม่ต้องติดตั้ง npm และไม่ต้อง build

## นำขึ้น GitHub Pages
1. แตกไฟล์ ZIP นี้
2. สร้าง repository บน GitHub หรือเปิด repository ที่ต้องการใช้
3. อัปโหลดไฟล์ทั้งหมดภายในโฟลเดอร์ที่แตกแล้ว ให้ index.html อยู่ที่ราก repository พร้อมกับ style.css, app.js, media.json และโฟลเดอร์ assets
4. เข้า Settings → Pages เลือก Deploy from a branch แล้วเลือก branch main และโฟลเดอร์ / (root) จากนั้นกด Save
5. รอ GitHub เผยแพร่ แล้วเปิดลิงก์ที่แสดงในหน้า Pages

อย่าอัปโหลดเฉพาะไฟล์ ZIP: ต้องแตก ZIP และอัปโหลดไฟล์ภายในก่อน
เส้นทางไฟล์เป็นแบบ relative รองรับทั้งเว็บหลักและ project Pages เช่น username.github.io/repository/

## โครงสร้างไฟล์
- index.html — หน้าเว็บภาษาไทย เนื้อหาบทความ กติกา เรื่องเล่า ทีม และอ้างอิง
- style.css — รูปแบบเว็บ ขนาดอักษร ระยะบรรทัด และ responsive layout
- app.js — เมนู ค้นหาบทความ กรองสื่อ และหน้าต่างรับชม
- media.json — รายการภาพและวิดีโอ
- assets/ — รูปภาพ อินโฟกราฟิก และภาพตัวอย่างวิดีโอ
- .nojekyll — ให้ GitHub Pages ให้บริการไฟล์ตรง ๆ

## เปิดดูบนเครื่อง
ใช้ VS Code พร้อมส่วนขยาย Live Server แล้วเลือก Open with Live Server ที่ index.html
หรือหากมี Python รัน python -m http.server 8000 ในโฟลเดอร์นี้ แล้วเปิด http://localhost:8000
ฉบับนี้ฝังรายการสื่อใน app.js แล้ว จึงเปิด index.html บนเครื่องได้โดยไม่ต้องโหลด media.json ผ่าน fetch และใช้กับ GitHub Pages ได้ด้วย

## การปรับแต่ง
แก้ข้อความใน index.html และรูปแบบใน style.css
ฟอนต์หลัก Noto Sans Thai สำหรับหัวข้อและเนื้อหา ส่วนข้อความคำคมใช้ Noto Serif Thai
โหลดฟอนต์จาก Google Fonts; หากไม่เชื่อมต่อจะใช้ฟอนต์สำรอง Tahoma / sans-serif

## สื่อและข้อจำกัด
มีภาพ 27 รายการ (รวมอินโฟกราฟิก 4 ชิ้น) และวิดีโอ 9 คลิปจาก Drive ตามเอกสารผู้จัดทำ
รูปภาพและภาพตัวอย่างแนบมาใน assets แล้ว วิดีโอเล่นผ่าน iframe Google Drive และต้องใช้อินเทอร์เน็ต รวมถึงสิทธิ์การดูไฟล์ต้นทางที่อนุญาตผู้เข้าชม
ช่อง TikTok เป็นลิงก์ค้นหา “บุษบา สตูดิโอ” เพราะเอกสารไม่ได้ระบุ URL บัญชีที่ยืนยันได้
ข้อมูลติดต่อมีเฉพาะบุคคลที่ระบุในเอกสาร ไม่ได้สร้างรายชื่อสมาชิกเพิ่มเติม
ข้อมูลประวัติศาสตร์และกติกาถอดจากเอกสารผู้จัดทำ รายการอ้างอิงที่ไม่มีลิงก์ยังไม่ได้ตรวจเอกสารฉบับเต็ม และควรใช้ประกาศของแต่ละสนามเป็นหลัก
โปรดตรวจสิทธิ์สื่อและข้อมูลติดต่อให้เหมาะสมก่อนเปิด repository และเว็บไซต์เป็นสาธารณะ

## ตรวจสอบฉบับนี้
ผ่านการตรวจ syntax JavaScript และการตรวจไฟล์สื่อทั้งหมดแล้ว ยังไม่ได้ทดสอบ layout และการเล่นวิดีโอจริงในเบราว์เซอร์

## แก้ไขปัญหาคลังสื่อ
ฉบับนี้ฝังรายการภาพ 27 รายการ และวิดีโอ 9 คลิปใน app.js จึงไม่ขึ้นกับการดึง media.json หากเพิ่มสื่อให้แก้รายการใน app.js ด้วย
