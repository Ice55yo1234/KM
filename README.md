# KM — มรดกสายน้ำ กวนวัน หนองคาย

## ฉบับปรับปรุงหน้าแผนที่แหล่งเรียนรู้
ใช้เอกสารใหม่ “แผนที่แหล่งเรียนรู้ภูมิปัญญาประเพณีแข่งเรือยาว” แทนเนื้อหาแผนที่ 5 จุดเดิม
หน้าแยก #learning-map มีเมนูถัดจากบทความและกติกา แบ่ง 3 กลุ่ม:
1. วัดในตำบลกวนวัน
2. ชุมชนบ้านกวนวัน: ฝีพาย นายหัวเรือ นายท้ายเรือ และผู้จัดการเรือ
3. แหล่งข้อมูลท้องถิ่นและสำนักงานเทศบาลตำบลกวนวัน
ใช้อินโฟกราฟิกฉบับใหม่ “แผนที่แหล่งเรียนรู้2.png” จาก Drive ของโครงการ
ภาพประกอบและคำอธิบายจากเอกสารใหม่ ภาพหน่วยงานใช้ประกอบแนวคิดตามเครดิตในเอกสาร ไม่ได้ระบุว่าเป็นภาพสำนักงานกวนวันจริง

## อัปเดตเว็บ
แตก ZIP และคัดลอกไฟล์ทั้งหมดในนี้ไปทับในโฟลเดอร์ GitHub โปรเจกต์ KM ให้ index.html อยู่ที่ราก พร้อม app.js, style.css, media.json และ assets/
จากโฟลเดอร์โปรเจกต์ที่เชื่อม GitHub แล้ว รัน:

git add .
git commit -m "Update community learning map"
git push origin main

GitHub Pages ใช้ branch main และโฟลเดอร์ / (root) ตามการตั้งค่าเดิม หลังเผยแพร่ให้รีเฟรช Ctrl+F5
ไม่ต้องใช้ npm หรือ build เปิดผ่าน Live Server หรือเปิด index.html ได้ รายการสื่อฝังใน app.js เพื่อเลี่ยงปัญหา fetch ไฟล์บนเครื่อง
วิดีโอใช้ Google Drive iframe ต้องใช้อินเทอร์เน็ตและสิทธิ์ดูไฟล์ต้นทาง
ฟอนต์ใช้ Google Fonts พร้อมฟอนต์สำรองบนเครื่อง

## โครงสร้าง
index.html — เนื้อหาและหน้าทั้งหมด
style.css — รูปแบบและรองรับมือถือ
app.js — เมนู หน้าเว็บ ค้นหา แกลเลอรี และหน้ารับชม
media.json — รายการสื่ออ้างอิง (เมื่อแก้รายการต้องอัปเดตข้อมูลที่ฝังใน app.js ด้วย)
assets/ — รูปภาพและอินโฟกราฟิก
.nojekyll — ให้บริการเป็นเว็บ static
